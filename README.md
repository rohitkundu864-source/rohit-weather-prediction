# Rohit Weather Prediction

A simple HTML/JavaScript web page that fetches today's weather for a given city using the OpenWeather API, with weather-based background colors.

## Setup

1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api).
2. Open `script.js` and replace `'YOUR_OPENWEATHER_API_KEY'` with your actual API key.

## Run

Simply open `index.html` in your web browser. No server required.

## Features

- Enter a city name.
- Click "Get Weather" to fetch and display current weather data (condition, temperature, feels like, humidity, pressure).
- Shows today + tomorrow aggregated forecast summary using 5-day forecast data.
- Background changes image based on weather condition (sunny/cloudy/rainy/snowy/thunderstorm).
